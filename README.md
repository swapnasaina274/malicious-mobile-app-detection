# Analysis of Malicious Mobile Application

## Project Summary
This project focuses on automated malicious mobile application detection and classification using the **CICMalDroid 2020** dataset and Machine Learning models.

## Current Project Status
- [x] Preprocessed CICMalDroid 2020 static/dynamic feature sets.
- [x] Trained Random Forest classifier and generated label encoders/scalers.
- [x] Exported model artifacts (`.pkl`) to Google Drive.
- [ ] Agentic AI / LangChain orchestrator integration (Next Step).
- [ ] Cloud Security Auditing with Prowler & Scout Suite (Next Step).
